# SFEDUCASTLING — Техническое задание
## С использованием ChessAgine (Mastra Framework)

---

## О проекте

**SFEDUCASTLING** — интеллектуальная шахматная платформа для обучения пользователей любого уровня.

**Основа:** ChessAgine — open-source AI агент с LLM, инструментами и базой знаний.

---

## Что берем из ChessAgine

### 1. База дебютов (ECO)
- Файлы: `ecoA.json`, `ecoB.json`, `ecoC.json`, `ecoD.json`, `ecoE.json`
- 5000+ дебютов с кодами ECO (A00-E99)
- Вместо нашей базы на 10 дебютов

### 2. Puzzle система
- 60+ тактических тем (fork, pin, mate, и т.д.)
- Уровни: Beginner, Intermediate, Advanced
- Темы: mateIn1, mateIn2, mateIn3, short, veryLong

### 3. AI Agent (Mastra)
- Фреймворк для создания агентов
- Инструменты через MCP (Model Context Protocol)
- Поддержка Ollama (локальные модели)

### 4. Display board
- Инструмент для показа позиции в чате
- Автоматическое отображение доски

### 5. Load game
- Загрузка партий из Lichess
- Загрузка PGN файлов
- Автоматический анализ через Stockfish

## Что добавляем к ChessAgine

### 1. Maia2 движок
- Инструмент: `maia_move_tool`
- Уровень игры: настраиваемый Elo
- Стиль игры: как человек

### 2. Адаптивное обучение
- Определение уровня (тест)
- Уровень 0: базовые правила
- Уровень 1: дебюты (из ECO базы)
- Уровень 2: миттельшпиль (тактика из puzzle)
- Уровень 3: эндшпиль (теория)

### 3. Генерация уроков
- LLM генерирует объяснения
- Агент использует puzzle_tool для задач
- Агент использует opening_tool для теории

### 4. Сбор данных
- Автоматический сбор ходов
- NAG аннотации (!!, !, ?!, ??)
