===============================================================================
                       CHESS COACH PIPELINE STRUCTURE
===============================================================================

chess_coach_pipeline/
│
├── chroma_db/                          # Локальный персистентный индекс ChromaDB
│   └── chroma.sqlite3                  # Хранилище векторов позиций (HNSW) и метаданных
│
├── data/                               # Каталог данных (поэтапное промежуточное хранилище)
│   ├── 01_raw/                         # Шаг 1: Исходные сырые позиции из PGN-партий
│   │   └── master_positions.jsonl      #   ├── FEN-строки, метаданные игроков (Elo, турнир) и сделанный ход
│   ├── 02_engine/                      #   └── (Временная/служебная папка движка)
│   ├── 02_engine_analyzed/             # Шаг 2: Результаты объективного анализа шахматным движком
│   │   └── master_analyzed.jsonl       #   └── FEN + лучший ход Stockfish + MultiPV + Centipawn Loss + ASCII
│   ├── 03_generated/                   # Шаг 3: Синтетические разборы от LLM-генератора
│   │   └── master_explanations.jsonl   #   └── Позиция + структурированный JSON по схеме CoachExplanation
│   ├── 04_validated/                   # Шаг 4: Результаты детерминированной технической фильтрации
│   │   ├── master_validated.jsonl      #   ├── Проверенные записи (легальные ходы FIDE, без пустых полей)
│   │   └── rejected.jsonl              #   └── Отбракованные записи с логом шахматных/структурных ошибок
│   └── 08_final_split/                 # Шаг 5: Финальный SFT-датасет для обучения
│       ├── train.jsonl                 #   ├── Обучающая выборка (80%) в формате ChatML
│       ├── val.jsonl                   #   ├── Валидационная выборка (10%) для отслеживания лосса
│       └── test.jsonl                  #   └── Тестовая выборка (10%) для финальной оценки качества
│
├── rag_module/                         # Векторный модуль поиска шахматных аналогий (Chess RAG)
│   ├── chessclip/                      # Исходный репозиторий архитектуры ChessCLIP (Waterhorse)
│   │   └── src/open_clip/              #   ├── Реализация FiLMModifiedResNet, модели ChessCLIP и конфиги
│   ├── models/                         # Веса нейросетевых моделей
│   │   └── chessclip.pt                #   └── Веса энкодера позиций (112 плоскостей -> 512-d вектор)
│   ├── board_converter.py              # Конвертер FEN -> 112 бинарных плоскостей LCZero (8x8)
│   ├── clip_encoder.py                 # Класс ChessPositionEncoder: прямой проход через FiLM-ResNet (L2-нормализация)
│   ├── vector_store.py                 # Класс ChessVectorStore: обертка над ChromaDB (upsert, cosine query)
│   ├── pgn_loader.py                   # Модуль индексации: обход партий PGN и пакетная заливка в ChromaDB
│   └── __init__.py                     # Инициализация пакета rag_module
│
├── scripts/                            # Исполняемые скрипты этапов пайплайна
│   ├── 01_extract_master_positions.py  # 1. Извлечение позиций из PGN: фильтрация (ходы 8–35, Elo >2400)
│   ├── 02_run_stockfish.py             # 2. Пакетный прогон Stockfish (глубина 22, MultiPV=3) на CPU
│   ├── 02b_build_rag_index.py          # 2b. Индексация базы знаний в ChromaDB через rag_module.pgn_loader
│   ├── 03_generate.py                  # 3. Генерация разборов LLM с подтягиванием похожих позиций из RAG
│   ├── 04_validate_examples.py         # 4. Проверка легальности ходов и валидности нотации через python-chess
│   ├── 05_prepare_sft_dataset.py       # 5. Сборка диалогов ChatML и разбиение на сплиты train / val / test
│   └── __init__.py                     # Служебный файл пакета scripts
│
├── src/                                # Переиспользуемые модули и логика ядра
│   ├── chess_engine.py                 # Обертка над Stockfish (SimpleEngine, MultiPV, centipawn loss)
│   ├── llm_api.py                      # Клиент взаимодействия с LLM API (Structured Outputs / JSON mode)
│   ├── prompts.py                      # Шаблоны системных промптов тренера (включая контекст из RAG)
│   ├── schemas.py                      # Pydantic-схемы (RawPosition, AnalyzedPosition, CoachExplanation, SimilarExample)
│   └── __init__.py                     # Инициализация пакета src
│
├── tests/                              # Автоматические тесты
│   ├── test_generate.py                # Тесты генерации, схем данных и подстановки промптов
│   └── test_vector_store.py            # Интеграционный тест: ChessCLIP -> ChromaDB -> поиск похожих позиций
│
├── requirements.txt                    # Зависимости (openai, pydantic, python-chess, torch, chromadb)
└── test_masters.pgn                    # Локальный PGN-файл гроссмейстерских партий для тестирования

===============================================================================
                       ПОЯСНЕНИЕ К НУМЕРАЦИИ DATA/
===============================================================================
Слоты 05, 06, 07 зарезервированы под расширение конвейера:
  - 05_llm_judged/     -> Оценка качества объяснений моделью-судьей (LLM-as-a-Judge)
  - 06_deduplicated/   -> Семантическая чистка и удаление дубликатов позиций
  - 07_balanced/       -> Балансировка тем (дебют / миттельшпиль / эндшпиль / тактика)
  - 08_final_split/    -> Итоговый срез данных на обучение
