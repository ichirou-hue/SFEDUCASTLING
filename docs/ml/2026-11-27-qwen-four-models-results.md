# Qwen3-1.7B: база и три LoRA на GigaBench

Обучение трёх LoRA и оценка всех четырёх моделей завершились без ошибок. Каждая модель получила одни и те же **8 657 запросов** (8 357 автоматических заданий + 300 комментариев). Для статических вопросов о клетках использовались FEN, числовая доска и вопрос; для комментариев — FEN, исходный вопрос и факты движка. Остальные задания, включая отслеживание позиции, получили FEN без числовой доски.

**Смесь — единственная LoRA, которая улучшила оба целевых показателя относительно базы.** Она сравнялась с моделью на комментариях по доле принятых объяснений (148/300), при этом скорер отметил критические ошибки в 45 ответах вместо 63 (−6,00 п. п.). На клетках смесь отстала от специализированной модели на 345 ответов (−19,40 п. п.). Если задача только в чтении клеток, лучший результат у клеточной LoRA.

Падение в блоке выбора хода — отдельная регрессия: смешанную LoRA нельзя считать улучшением по всем шахматным задачам. Низкий M6-auto сам по себе не означает хорошие объяснения: клеточная LoRA не прошла ни одного комментария. M4–M7-auto — эвристики, а не экспертная оценка пользы объяснений.
