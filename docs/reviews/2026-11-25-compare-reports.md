## Находки
- Закрыто 🔴 — `ml/gigabench/tools/compare_reports.py:72–77` теперь сверяет SHA256 фактических manifest и responses с полями обоих JSON. Тест `test_summary_from_other_model_is_rejected` воспроизводит подмену summary при одинаковом manifest и разных responses и ожидает отказ.
- 🟡 Частично закрыто — `tests/ml/gigabench/test_compare_reports.py:84–127` добавлены отказы для input profile и Stockfish, а также порчи каждого из девяти pair-артефактов с восстановлением между проверками. Остаются отсутствующими тесты сравнения разных pair, различий config/scorer, mock и входа через `summary.json`. Предложение: добавить эти негативные сценарии и проверку файлового входа; замечание неблокирующее.

## Что хорошо
- Используется `correct / records`, включая неопределённые ответы в знаменателе; дельта рассчитывается в процентных пунктах.
- Есть HTML escaping, проверка покрытия и защита выходного файла от перезаписи.
- Для pair проверяются SHA256 существенных файлов и совпадение корневого каталога.

Повторная проверка ограничена закрытием двух исходных замечаний. Запуск тестов повторно не выполнен: инструмент отклонил команду по разрешениям; выводы основаны на чтении кода.
